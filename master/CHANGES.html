What changed in master/, and why

Two changes, both large The résumé now carries the VoltusWave · Amura work — new headline, new summary, four new skills lines, four new experience bullets, and one factual correction. And three files became one: there is now a single master résumé instead of a parsed copy, a hand-paste copy and a template that could silently drift apart.

What made the merge possible. The two files existed because of a real conflict: upGrad's paste sanitiser strips bold from list-rooted content, so anything you copy by hand must be standalone <p> — but the parser only understood <ul><li>, and returned an empty list for anything else. Worse, its callers silently skip an empty section, so a <p>-based file would have exported a résumé with sections missing and still looked successful. _ul_items_html now reads both shapes, verified against the real parser with bold preserved in each. One file can now be both hand-pasted and bot-parsed.

2 · The résumé itself

2.1 · New headline

Before

Principal Software Architect — multi-tenant SaaS platforms, Java and Spring Boot microservices, and production AI on AWS

Now

Principal Software Architect — Java and Spring Boot microservices, multi-tenant SaaS platforms, and production AI where deterministic code owns every number

How it was chosen: five drafts from different angles — Java-first, AI-depth, platform, regulated, hybrid — scored by three independent judges: a recruiter lens, a hiring-engineer lens and an honesty auditor. 2.4 · Engineering Excellence — six lines to ten

Two existing lines were extended rather than duplicated: stores gained Elasticsearch dense_vector, Redis and DuckDB and Parquet; the AWS line gained SageMaker and Neptune with Gremlin. Four lines are new — causal inference on observational data, leakage-safe machine learning, deterministic replayable systems, and self-hosted models inside the virtual private cloud.

Why: a gap analysis against the ten case studies found this named repeatedly in your own documents and entirely absent from the résumé — DuckDB and Parquet in 8 studies each, Redis in 7, Ollama in 6, self-hosted LangSmith in 9. Skills lines carry no number requirement, so none of it depends on metrics you cannot supply.

  • Hardened — ten services through adversarial self-review, twenty findings absorbed, one held dark until its upstream contract shipped
