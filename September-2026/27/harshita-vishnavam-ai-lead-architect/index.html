Glossary: every acronym and unfamiliar term on this page, expanded (23)
  • JD: job description. It is the abbreviation behind the jd.md and jd.html filenames, and behind “Full-time JD workspace” in the breadcrumb at the top of this page.
  • AI: artificial intelligence.
  • TAG: talent acquisition group, the recruiting team. Her signature writes only the letters.
  • InMail: a LinkedIn message that can reach people the sender is not connected to.
  • URL: uniform resource locator, the web address of a posting. The tracker row’s source_url is NULL rather than a sentence, because the launcher page shows that column as a link.
  • Tracker: the database jobs_tracker_v2, which records every seat. The launcher page reads its list of applications from it.
  • Slug: the workspace’s short name, harshita-vishnavam-ai-lead-architect, used for its folder and its tracker row.
  • NULL: the database’s way of saying a column has no value.
  • Weighted rubric: the scoring table behind the technical score. Each requirement gets a weight, a score out of ten, and the evidence behind that score.
  • ML: machine learning, the part of AI in which a system learns patterns from data.
  • Generative AI: AI that creates new text, images or code.
  • LLM: large language model, the kind of AI model behind chat assistants, trained on very large amounts of text.
  • RAG: retrieval-augmented generation. The model answers from documents fetched at question time, not only from what it learned in training.
  • Agentic AI: AI in which a language model plans and carries out several steps toward a goal, such as calling tools or other programs.
  • Azure: Microsoft’s cloud platform. Azure OpenAI: Microsoft’s service that runs OpenAI’s models on Azure. OpenAI: the company that makes those models, which it also offers directly.
  • LangChain: an open-source framework for building applications on large language models.
  • Semantic Kernel: an open-source development kit from Microsoft for building AI applications and agents on large language models.
  • AutoGen: an open-source framework from Microsoft for applications in which several AI agents work together.
  • AWS: Amazon Web Services. GCP: Google Cloud Platform. Both are cloud platforms, like Azure.
  • Governance: the rules and controls an organisation sets for how its AI systems are built and used.
  • Notice period: the time a person must keep working after resigning, before joining a new employer. An immediate joiner can start without serving one.
  • Microsoft Forms: Microsoft’s online form tool.
  • Favicon: the small icon shown on the browser tab.
