Glossary — every acronym and domain term on this page, expanded (44)
  • JD — job description
  • IC — individual contributor: an engineering track with no people-management mandate
  • PDF — Portable Document Format
  • JSON — JavaScript Object Notation, the format score.json is written in
  • EHR — electronic health record: the system of record for a patient’s clinical history, which is ModMed’s product
  • PHI — protected health information: patient data that United States law restricts the handling of
  • HIPAA — Health Insurance Portability and Accountability Act, the United States health-data privacy law
  • ISO 27001 — the International Organization for Standardization’s information-security management standard. A different employer and a different certification from the HIPAA work — Deque, not VoltusWave
  • HL7 / FHIR — Health Level Seven, and its Fast Healthcare Interoperability Resources standard: how clinical systems exchange records. Named nowhere in this posting, and absent from his record
  • ONC certification — the United States Office of the National Coordinator’s certification programme for health information technology
  • SaaS — software as a service
  • DDD — Domain-Driven Design: modelling software around the business domain, with bounded contexts (an explicit boundary inside which one model and one vocabulary hold), aggregates (a cluster of objects changed as one unit) and a ubiquitous language shared by engineers and domain experts
  • CQRS — Command Query Responsibility Segregation: separating the write path from the read path so each can be modelled and scaled on its own
  • Event sourcing — storing the sequence of changes as the system of record, and deriving current state from it, rather than storing only the latest state
  • Event streaming — a durable, ordered, replayable log that many consumers read independently. Kafka and NATS are two products; Amazon Kinesis is another, and it is the one he has run in production
  • Shard / partition — one ordered slice of a stream. Kinesis calls it a shard; Kafka calls it a partition. The same idea under two names
  • Enhanced Fan-Out — the Kinesis feature giving each consumer its own dedicated read throughput instead of sharing the shard’s
  • Reactive programming — non-blocking, asynchronous streams with backpressure (a consumer signalling upstream that it cannot keep up). Project Reactor, RxJava and Spring WebFlux are its Java implementations. Adjacent to, and not the same as, asynchronous or event-driven work
  • Distributed cache grid — a cache spread across many nodes and shared by many services. Hazelcast, Ignite and Coherence are named products; Redis is the one in his record
  • Cache stampede — many requests missing the same cold key at once and all recomputing it. Single-flight locking is the fix: one request computes, the rest wait
  • TTL — time to live: how long a cached entry stays valid
  • P95 / P99 — the 95th and 99th percentile of a latency distribution: the slow tail, not the average
  • Observability — being able to tell what a running system is doing from its own output: metrics, logs and traces
  • CI/CD — continuous integration / continuous delivery: automated build, test and release
  • API — application programming interface
  • REST — representational state transfer
  • AWS — Amazon Web Services
  • ECS — Elastic Container Service, Amazon’s container orchestrator
  • Fargate — the ECS mode where Amazon runs the container host, not you
  • Spot — spare Amazon capacity at a discount, reclaimable at short notice
  • RDS — Relational Database Service, Amazon’s managed database service
  • Aurora — Amazon’s managed PostgreSQL- and MySQL-compatible database engine
  • VPC — virtual private cloud: a network isolated to one tenant
  • AZ — availability zone: one physically isolated data centre within a cloud region
  • HA — high availability: designing so a component failure does not take the service down
  • DR — disaster recovery
  • NoSQL — non-relational databases: key-value, wide-column, document, search and graph stores
  • ELK — Elasticsearch, Logstash and Kibana: a log and search stack
  • SSO — single sign-on
  • OIDC / OAuth 2.0 — OpenID Connect, and the authorisation framework it sits on
  • JWT — JSON Web Token: a signed token carrying claims, here the tenant identity on every request
  • GNN — graph neural network
  • LLM — large language model
  • QA — quality assurance
  • k6 — an open-source load-testing tool (a proper noun, not an acronym)
