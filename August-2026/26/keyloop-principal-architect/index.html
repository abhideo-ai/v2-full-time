  • JD — job description
  • IC — individual contributor: an engineering track with no people-management mandate. This posting names itself one
  • DMS — dealer management system: the software a car dealership runs its whole business on — sales, service, parts, inventory, finance. Keyloop’s product category, and a new domain for him
  • SaaS — software as a service
  • PDF — Portable Document Format
  • JSON — JavaScript Object Notation, the format score.json is written in
  • AI — artificial intelligence
  • Agent orchestration — coordinating multiple AI model calls, tools and checkpoints into one governed workflow; LangGraph is the framework he ran, with state checkpointed in PostgreSQL
  • MCP — Model Context Protocol: an open standard letting AI assistants call external tools and data sources; he has built real MCP servers (user-confirmed; deliberately carried without a number)
  • LLM — large language model
  • GNN — graph neural network: a model that learns over nodes and edges rather than rows; his runs on the Context Graph beside Amazon Neptune
  • RAG — retrieval-augmented generation: retrieving relevant documents first and generating an answer grounded in them
  • Claim grammar — his guardrail design: a typed schema for model output where every claim must carry a citation, making an uncited claim unrepresentable — live on killer query 1 (KQ1)
  • AWS — Amazon Web Services; GCP — Google Cloud Platform (named only in the posting’s certification line; not his)
  • ECS / Fargate / Spot — Elastic Container Service, Amazon’s container orchestrator; Fargate is its serverless mode; Spot is spare capacity at a discount, reclaimable at short notice
  • RDS / Aurora — Relational Database Service, Amazon’s managed database service, and its PostgreSQL/MySQL-compatible engine
  • VPC — virtual private cloud: a network isolated to one tenant; “in-VPC” model hosting means patient data never leaves the client’s boundary
  • AZ / HA / DR — availability zone (one isolated data centre in a region); high availability; disaster recovery
  • SRE — site reliability engineering: running production systems against explicit reliability targets
  • SLA — service-level agreement
  • ELK — Elasticsearch, Logstash and Kibana: a log and search stack
  • CI/CD — continuous integration / continuous delivery: automated build, test and release
  • API — application programming interface
  • ROI — return on investment
  • ESB — enterprise service bus: middleware routing and transforming messages between systems; MuleSoft is the product he used
  • SOA — service-oriented architecture (named in the posting’s nice-to-have list)
  • JWT — JSON Web Token: a signed token carrying claims, here the tenant identity on every request
  • SSO / OIDC / OAuth 2.0 — single sign-on; OpenID Connect; and the authorisation framework it sits on
  • RBAC — role-based access control
  • HIPAA — Health Insurance Portability and Accountability Act, the United States health-data privacy law. His HIPAA work is VoltusWave’s chat platform and pipelines
  • ISO 27001 — the International Organization for Standardization’s information-security management standard. A different employer and a different certification from the HIPAA work — Deque, not VoltusWave
  • PHI — protected health information: patient data that United States law restricts the handling of
  • WCAG — Web Content Accessibility Guidelines, the standard Deque’s accessibility products report against
  • NoSQL — non-relational databases: key-value, wide-column, document, search and graph stores
  • CQRS — Command Query Responsibility Segregation: separating the write path from the read path so each can be modelled and scaled on its own
  • Event sourcing — storing the sequence of changes as the system of record, and deriving current state from it
  • Event streaming / shard / Enhanced Fan-Out — a durable, ordered, replayable log read by many consumers; a shard is one ordered slice of it (Kafka calls it a partition); Enhanced Fan-Out is the Kinesis feature giving each consumer dedicated read throughput

  • TTL — time to live: how long a cached entry stays valid
  • P95 / P99 — the 95th and 99th percentile of a latency distribution: the slow tail, not the average
  • MDM — master data management: reconciling one authoritative record from many sources (the McDonald’s engagement)
