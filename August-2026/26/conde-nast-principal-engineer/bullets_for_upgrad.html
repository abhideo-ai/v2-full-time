Read this before pasting anything

The exporter is the path, and it needs none of this. automation/upgrad_apply.py overwrites all ten parsed sections from upgrad_resume.html on every run, dispatching a synthetic clipboard event that Draft.js honours natively. That is where the formatting actually survives. This page exists for two narrower jobs: reading what the bot is about to write, and the occasional one-off single-line fix in the Hiration user interface, where a lone paragraph pastes cleanly.

Every bullet below is a standalone paragraph, never a list item. upGrad’s paste sanitiser strips bold from list-rooted content, so a <ul> would silently lose every bolded fact on the way in and it would not surface until the exported PDF (Portable Document Format). There are no styled <span> elements here either — upGrad strips those too. Each copy button carries data-copy-html="1", which puts real <strong> on the clipboard rather than a hand-dragged selection that loses it.

One block, one paste, and never a merge. Copy a block and it replaces its counterpart whole. Do not paste one of these into an existing bullet, and do not paste two at once — several paragraphs pasted together collapse into a single line. If a section needs replacing wholesale rather than one line fixed, use the whole-section copy buttons in upgrad_resume.html, which is the file the exporter reads.
