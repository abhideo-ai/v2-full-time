Glossary — every acronym and domain term on this page, expanded
  • JD — job description
  • IC — individual contributor: an engineering track with no people-management mandate
  • InMail — LinkedIn’s paid direct-message product, the channel the recruiter used on 6 August
  • PDF — Portable Document Format
  • JSON — JavaScript Object Notation, the format score.json is written in
  • AI — artificial intelligence
  • Agentic AI — systems where a language model participates in multi-step work — planning, calling tools, coordinating with other agents — rather than answering a single prompt
  • LLM — large language model
  • MCP — Model Context Protocol: an open standard through which a language-model client calls external tools and data sources; an “MCP server” exposes such tools
  • Multi-agent pipeline — several model-backed agents composed into one flow; here, KQ10’s three “finder” personas fanning out in parallel behind a re-verifying barrier
  • Orchestration / state graph — the fixed control flow that sequences agent and code steps; LangGraph expresses it as a compiled graph whose edges are code, not model choices
  • Guardrail / claim grammar — a validator on model output; the field-level claim grammar requires every factual sentence to decompose into allowed templates backed by cited fields and edges that actually exist
  • Narrator — the language-model component that would write prose summaries over computed results; on KQ9/KQ10 it ships off by default pending a signed guardrail contract
  • Evaluation harness / golden set — a fixed, versioned test corpus a retrieval or analytics system is scored against before it may serve
  • NDCG@10 — Normalized Discounted Cumulative Gain over the top ten results: a ranking-quality metric
  • RAG — retrieval-augmented generation: retrieving evidence first, then letting a model work only over what was retrieved
  • GNN — graph neural network
  • KQ — killer query: one of the ten flagship analytics questions in the case-study corpus (KQ1…KQ10)
  • In-VPC / VPC — virtual private cloud: a network isolated to one tenant; self-hosting models in-VPC keeps patient data inside the client boundary
  • AWS — Amazon Web Services
  • ECS / Fargate / Spot — Elastic Container Service, Amazon’s container orchestrator; Fargate is its serverless mode; Spot is discounted spare capacity, reclaimable at short notice
  • RDS / Aurora — Relational Database Service, Amazon’s managed databases; Aurora is its PostgreSQL- and MySQL-compatible engine
  • AZ / HA / DR — availability zone (one isolated data centre in a region); high availability; disaster recovery
  • Shard / Enhanced Fan-Out — one ordered slice of a Kinesis stream; Enhanced Fan-Out gives each consumer dedicated read throughput
  • ELK — Elasticsearch, Logstash and Kibana: a log and search stack
  • P95 / P99 — the 95th and 99th percentile of a latency distribution: the slow tail, not the average
  • SaaS — software as a service
  • HIPAA — Health Insurance Portability and Accountability Act, the United States health-data privacy law — the VoltusWave chat platform’s certification driver. A different employer and different certification from ISO 27001, which is Deque’s
  • ISO 27001 — the International Organization for Standardization’s information-security management standard
  • CI/CD — continuous integration / continuous delivery: automated build, test and release
  • API — application programming interface; REST — representational state transfer
  • QA — quality assurance; UX — user experience
  • SSO / OIDC / OAuth 2.0 — single sign-on; OpenID Connect; and the authorisation framework it sits on
  • RBAC — role-based access control; JWT — JSON Web Token, a signed token carrying claims
  • ESB — enterprise service bus, the MuleSoft integration backbone at Teletext
  • k6 — an open-source load-testing tool (a proper noun, not an acronym)
  • ATS — applicant tracking system
