The format this page uses when it has bullets

Recorded so the shape is not re-derived later. Each changed bullet is a standalone <p> carrying raw <strong> — never inside a <ul> or <li>, because upGrad strips bold from list-rooted content, and never a styled <span>, because upGrad strips those too. Every copy button carries data-copy-target="#id" data-copy-html="1" so the bold survives the clipboard. Bullets are derived by comparing this workspace's résumé against the master, never retyped.
