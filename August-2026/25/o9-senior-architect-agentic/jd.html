Role summary

Define, own and evolve the end-to-end architecture of an increasingly artificial intelligence (AI)-heavy enterprise platform. Technical authority across the organization: set architectural direction, establish standards, ensure successful production deployment of advanced data, software and AI systems. Operates at the intersection of deep learning, data engineering, software engineering and machine learning operations (MLOps), driving long-term platform strategy while partnering with engineering leadership.

Stated focus Enterprise platform architecture · MLOps · deep learning deployment

Key responsibilities

Six items, in the posting's own order.

  1. Define and evolve end-to-end enterprise platform architecture
  2. Build scalable, secure data pipelines for structured and unstructured data
  3. Lead MLOps practices: continuous integration and continuous delivery (CI/CD) for machine learning, model registries, retraining pipelines, drift detection
  4. Design and deploy deep learning and agentic models — for example retrieval-augmented generation (RAG) and vector database integration
  5. Mentor engineers, set standards, lead reviews
  6. Balance short-term delivery with long-term platform evolution
